# DARA — ランディングサイト

友達だけが集まる、3Dでかわいいグループ型のスレッドSNS「DARA」の紹介サイト。

黒い背景に、真珠のように光る白いふくらんだ3D。フレームワークなしの HTML / CSS / JavaScript と three.js で作っています。

## 3Dの体験

| 場所 | 内容 |
| --- | --- |
| ヒーロー | WebGLで描いた真珠の「DARA」ロゴ。マウス・端末の傾きで傾き、ドラッグで回転（慣性つき・正面に戻る）、タップでぷるんと弾む |
| コンセプト | パステルのバルーンカード。触ると傾き、光の当たり方が変わる |
| グループ | 顔つきの丸いキャラクター6体。ポインターの方を見て、タップするとジャンプ |
| スレッド | スクロールに合わせて向きが変わるスマホ画面のモック |
| ボタン | 空気で膨らませたような真珠色のボタン。押すとぷにっと沈む |

`prefers-reduced-motion` のときは動きを止め、WebGLが使えない環境では文字のロゴに切り替わります。

## ファイル構成

```
index.html
css/style.css
js/main.js        ページ全体（スクロール表示・カードの傾き・3Dの読み込み）
js/lib.js         3D共通（レンダラー・真珠の質感・バネ）
js/logo.js        DARAロゴ
js/characters.js  グループのキャラクター
assets/favicon.svg
```

アプリへのリンク先は `js/main.js` の `APP_URL` で変更できます。

## ローカルで見る

ES Modules を使っているので、ファイルを直接開かずにサーバー経由で開きます。

```sh
npx http-server -c-1 .
# http://localhost:8080
```

## 公開

ビルド不要の静的サイトなので、Cloudflare Pages / Workers の静的アセットなどにそのまま置けます。
