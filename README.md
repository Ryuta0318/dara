# DARA

友達だけが集まる、3Dでかわいいグループ型のスレッドSNS「DARA」の紹介サイト。

黒い背景に、真珠のようにふくらんだ3D。ビルド不要の HTML / CSS / JavaScript と three.js（`public/vendor` に同梱）で作っています。

## リポジトリの構成

| 場所 | 中身 |
| --- | --- |
| `public/` | 紹介サイト（ランディング）。Cloudflare Workers の静的アセットとして公開（`wrangler.jsonc`、Worker名 `dara`） |
| `app/` | アプリ本体（友達だけのスレッドSNS）。Worker + Durable Object（SQLite）+ 静的な画面（`app/wrangler.jsonc`、Worker名 `dara-app`） |

### アプリ（`app/`）

- 招待コードなしで登録できます。登録すると、自分だけの部屋「ひとりごと」が最初から1つできます。
- 友達の追加は、IDで探す・QRを見せる / 読み取る・リンクを共有、の3通りです。
- 部屋は誰でもつくれます。部屋ごとに8文字のコードがあり、コード・リンク・QRのどれでも入れます（友達でなくても入れます）。コードは、メンバーなら誰でも作り直せます。
- 部屋は、名前・色（12色＋自由な色）・キャラクターの形（8種）と顔（12種）・ひとこと・背景の模様を、メンバーなら誰でも変えられます。
- 投稿とコメントに、スタンプでリアクションできます（同じスタンプをもう一度押すと外れます）。スタンプだけのコメントも送れます。
- スタンプは、形（8）・色・顔（12）・文字（8文字まで）・かざり・かたむきを組み合わせて、自分でいくつでも（100個まで）つくれます。ほかの人のスタンプも、自分用にコピーできます。スタンプは画像ではなく、設計図（数字と文字）だけを保存し、画面でSVGとして描きます。
- 部屋の見た目は、背景の写真・タイトルの書体（10種類）・かざりのスタンプ（4つまで）も変えられます。
- 部屋のオーナー（つくった人）は、メンバーを外す・オーナーをゆずる・部屋を削除する・見た目の変更を「オーナーだけ」にロックする、ができます。
- 投稿とコメントは、自分のものを編集・削除できます。オーナーは、ほかの人の投稿も削除できます。
- スタンプは、文字の書体（10種類）、文字だけのスタンプ、自分の写真から作るスタンプにも対応しています（写真は自分がアップロードしたものだけ使えます）。
- 友達とは1対1のDMができます（文字・写真・スタンプ・リアクション、未読の数字つき）。
- **動画**も投稿できます（スレッド・コメント・DM。1つの投稿に1本、30MBまで（スマホの動画で30秒〜1分くらい））。写真ボタンから選ぶと、最初の1コマが表紙になり、タップするとその場で再生します。iPhone の Safari が使う Range（部分取得）にも対応しています。iPhone で撮った HEVC の動画は、Android や PC の Chrome では再生できないことがあります（そのときはダウンロードのリンクが出ます）。
- **写真・動画の置き場**：いまは Durable Object のデータベース（無料で約 5GB）。Cloudflare R2 に移すときは、`app/wrangler.jsonc` の `r2_buckets` の行を有効にしてデプロイします。R2 をつなぐと、新しいものは R2 に保存され、入っている写真も見られたときと1日5回の定期処理で少しずつ R2 に移ります。
- プロフィールに自己紹介を書けます。
- **ユーザーID（@〜）はあとから変えられます**（プロフィールを編集 →「ユーザーIDを変える」、いまのパスワードで確認、1日3回まで）。変える前のIDも30日間はその人につながり（前の投稿のメンション・友達追加のリンク・ログイン）、そのあいだほかの人は使えません。管理者は `ADMIN_HANDLES` のIDも書き換えてください。
- **スマホへのプッシュ通知**（Web Push）。アプリを閉じていても、コメント・メンション・スタンプ・友達申請・DMが届きます。設定から、端末ごとにオン・オフでき、「DM」と「そのほか」を別々に切れます。
  - Android（Chrome）は、そのまま使えます。
  - iPhoneは、Safariの共有ボタン →「ホーム画面に追加」して、そのアイコンから開いたときに使えます（iOS 16.4以上）。
  - 鍵（VAPID）は、最初に自動でつくられ、データベースに保存されます。設定は要りません。
  - 暗号化と署名は `app/src/push.js` に自前で実装しています。`node app/test/push.test.mjs` で、受け取る側の手順と突き合わせて検証できます。
- 部屋のバナーの右上の⚙から、部屋の設定（招待コード・メンバー・オーナーの設定など）を開けます。
- 部屋のカスタマイズ画面は、上に「完成イメージ」が固定で出ます（部屋の中 / ホームのカード を切り替え可能）。実際の画面と同じ部品で描くので、そのままの見た目です。
- 通知（コメント・返信・メンション・スタンプ・友達申請・通報）を、ホームの🔔から見られます。未読の数字は、ブラウザのタブのタイトルにも出ます。
- 本文に `@ユーザーID` を書くと、相手に通知が届きます（入力中は候補が出ます）。URLは自動でリンクになります。
- 投稿・コメントを探せます（ホームの検索と、各部屋の「探す」）。
- スレッドは、ピン留め（1部屋3つまで）、アンケート（選択肢2〜6個・投票の取り消し可）にできます。コメントには返信（1段の入れ子）できます。
- 書きかけは、下書きとして端末に残ります。
- ブロック（相手の投稿が見えなくなる・友達が解除される）と通報ができます。通報は、部屋のオーナーに匿名で知らされます。
  管理者（`app/wrangler.jsonc` の `ADMIN_HANDLES` に入れたユーザーID）は、プロフィール →「プライバシーと安全」から、すべての通報を見られます。
- DMに既読が付きます（設定でオフにできます。オフにすると相手の既読も見えません）。
- スタンプのリアクションは、長押しで「押した人」が見られます。
- パスワードの再設定：登録時に1度だけ表示される復旧コードで戻せます（既存の人は、「プライバシーと安全」から作れます）。パスワードの変更もできます。
- 登録は同じ回線から1時間に10人まで、ログイン失敗は10分に8回まで、コードの入力は10分に30回までです。

```sh
# ローカルで動かす
npx wrangler dev --config app/wrangler.jsonc
# 公開する
cd app && npx wrangler deploy
```

`setroom` のデータは、新しい `dara-app` には引き継がれません（別のDurable Objectです）。

## オープニング

トップを開くと、演出から始まります（約3秒）。真珠が1粒落ちて弾み、光の輪が広がり、カメラが引きながら「DARA」の文字が1つずつ落ちて着地、笑顔の曲線が出て、光が走り、まわりの玉が飛んできます。そのあとメニューとキャッチコピーが、ふわっと出ます。

- タップ・キー操作・スクロールで、いつでも飛ばせます。
- フッターの「オープニングをもう一度」で、見直せます。
- 次のときは出しません：「動きを減らす」設定 / 途中のセクションへのリンクで開いたとき。
- 3Dが使えない環境では、ロゴ画像がぽよんと出ます。

## 3Dの体験

| セクション | 内容 |
| --- | --- |
| Home | 風船のようにふくらんだ真珠の「DARA」。傾き・ドラッグで回転・タップでぷるん。まわりにパステルの玉が浮かぶ |
| About | ぷっくりした真珠のアイコン（招待制 / 雑談 / 写真 / 秘密）。タップでくるっと回る |
| Rooms | 星・ハート・花などの形をしたキャラクターが、つやのある床に並ぶ。タップでジャンプして部屋の名前が出る |
| Play | 部屋のカードの山（タップ / スワイプで次へ）と、その部屋のチャット。メッセージを送ると返事が来る |
| Features | できること / はじめかた / やらないこと |

- 文字やキャラクターの形は、2Dの形を「ふくらませる」距離関数から Surface Nets でメッシュ化しています（`public/js/sdf.js`、Web Worker で並列処理）
- 日本語 / 英語の切り替え（JP | EN）
- `prefers-reduced-motion` のときは動きを止め、WebGL が使えない環境では画像のロゴに切り替え

## ファイル構成

```
public/                公開するファイル一式
  index.html
  css/style.css
  js/main.js           ページ全体（言語・カードの山・チャット・スクロール表示）
  js/lib.js            3D共通（レンダラー・質感・メッシュ化の Worker プール）
  js/sdf.js            ふくらんだ形の距離関数と Surface Nets
  js/mesher-worker.js
  js/hero.js           DARAロゴ
  js/icons.js          Aboutのアイコン
  js/rooms.js          Roomsのキャラクター
  assets/              ロゴ・OG画像・アイコン（tools で3Dから書き出し）
  vendor/three/        three.js r170（MIT）
tools/                 ロゴ画像を書き出すためのページとスクリプト
wrangler.jsonc         Cloudflare Workers で公開する設定
```

アプリへのリンク先は `public/js/main.js` の `APP_URL` で変更できます。

## 公開

公開先のドメインは **dara-app.com**。

1. dara-app.com を取得し、Cloudflare にサイトとして追加する（Cloudflare Registrar で取得すれば自動で追加される）
2. `npx wrangler deploy` で公開すると、`wrangler.jsonc` の `routes` により `dara-app.com` と `www.dara-app.com` に紐づく

`index.html` の canonical / OG の URL も `https://dara-app.com/` にしてあります。

## キャラクター画像の入れ方

部屋のキャラは `app/public/animals/<名前>.webp`（`gorilla` `bear` `rabbit` `cat` `fox` `penguin`）があればその画像を使い、無ければ内蔵の SVG で代用します。
ChatGPT などで「真っ黒な背景・真珠のような白い立体キャラ」を作り、`tools/cutout.html` をブラウザで開いて入れると、背景が透明な WebP になります。
色の変更は、画像の上に色を重ねて表現します（白いキャラほど綺麗に色が変わります）。

## 部屋の背景・デコの画像

背景は `app/public/scenes/<名前>.webp`（`room` `forest` `sea` `space` `snow` `sky` `candy` `night`）、デコは `app/public/decor/<名前>.webp`（`sofa` `plant` `lamp` `neon` `mushroom` `tree` `shell` `star`）に入れると、その画像を使います。無い間は色とえもじで代用します。
デコは背景が透明なので、キャラと同じく `tools/cutout.html`（黒背景 → 透明）を通してください。背景は切り抜かず、そのまま WebP にします。
